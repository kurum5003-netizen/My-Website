# My-Website

Bu proje, hastane süreçlerini dijital ortamda yönetmek amacıyla geliştirilmiş bir web tabanlı hastane otomasyon sistemidir.

---

# 🚀 Özellikler

- Hasta kayıt ve giriş sistemi
- Doktor giriş sistemi
- Admin paneli
- Randevu oluşturma
- Randevu görüntüleme ve yönetme
- Reçete oluşturma
- Hasta bilgilerini görüntüleme
- Veritabanı destekli dinamik yapı
- Güvenli oturum kontrol sistemi
- Responsive tasarım

---

# 🛠 Kullanılan Teknolojiler

## Frontend
- HTML5
- CSS3
- JavaScript

## Backend
- PHP

## Veritabanı
- MySQL

---

# 📂 Proje Yapısı

- `admin/` → Admin panel dosyaları
- `doktor/` → Doktor işlemleri
- `hasta/` → Hasta işlemleri
- `includes/` → Ortak PHP dosyaları
- `ortak/` → Veritabanı bağlantıları ve yardımcı dosyalar
- `assets/` → CSS, JS ve görseller
- `index.php` → Ana giriş sayfası
